# Evaluation approach

The project considers:

- Bitrate measured from actual encoded outputs.
- Reconstruction quality and perceptual metrics.
- Independent decoding and reconstruction-consistency checks.
- Comparison with appropriate conventional and research baselines.
- Repeated trials and controlled comparisons before making strong claims.

These are evaluation principles, not a claim that every test has already been completed. Detailed protocols, numerical outcomes, and unpublished methods remain private.
